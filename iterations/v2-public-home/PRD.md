# v2 Public Home · 参赛主页与公开试用页

## 背景

教考智联将参加第三十届辽宁省教育教学信息化交流活动的“人工智能+教育案例”方向。公开主页需要同时承担参赛展示、真实体验入口和角色分流入口，让评审、老师、学生和访客快速理解平台价值并能直接试用。

## 目标

- 公开展示教考智联作为专升本《计算机应用基础》AI 教与学工作台的定位。
- 说明“Qwen 原始资料结构化 + A/B/C Notion Agent 生成 + 教师人工审核 + 学生学习闭环”的核心流程。
- 提供无需登录的试用教学页入口，避免访客因没有账号无法体验。
- 提供学生端登录/申请访问和老师端登录入口。
- 用克制、可核验的方式展示应用成效与前期实践基础。

## 页面范围

### `/`

公开主页，所有用户可访问。即使已经登录，访问 `/` 也必须继续显示公开主页，不自动切到老师端或学生端。主页包含：

- 顶部导航：案例简介、AI 工作流、教学闭环、应用成效、体验入口。
- 第一屏：教考智联定位、参赛标识、核心说明和三个入口按钮。
- AI+教育案例亮点：智能助教、智能助学、可控发布。
- A/B/C 智能体工作流：资料上传、A 考点、B 真题、C 教学页、人工审核、发布到学生端。
- 学生学习闭环：进入章节、阅读教学页、完成练习、参加模拟考试、回看错题。
- 老师备课闭环：章节同步、资料上传、A/B/C 生成、审核、授权、导出。
- 应用成效与实践基础：6 章、369 道真题、约 4 小时压缩到约 20 分钟、桌面版参赛一等奖但证书待下发。
- 底部可信说明：课程边界、授权、公开试用、人工审核和竞赛成果表述边界。

### `/trial`

无需登录的公开只读试用章节。固定展示当前数据库 `chapters.id = 26` 的 `第 1 章第 1 节-计算机概述`，读取该章节最新教学页 markdown 和未隐藏、非重复保留的练习题。试用页只用于公开体验，不写入练习记录、错题记录或授权关系。

试用页底部“正式课程会提供什么”使用图文卡片展示章节教学页、历年真题练习、模拟考试、错题回看、资料下载、老师授权开放。前五项使用学生端界面截图，老师授权开放使用项目风格示意图；卡片只做功能说明，不作为无需登录入口。

### `/login?role=student`

学生端登录 / 申请访问入口，复用现有认证接口。

### `/login?role=teacher`

老师端登录入口，复用现有认证接口。首次无老师账号时仍显示初始化老师账号。

### `/teacher`

老师工作台入口。老师登录成功后跳转到该路径。

老师端流程区按模型生成能力和公共管理能力分区展示：

- `Qwen 原始页面`：上传资料并生成 Markdown 原始页，可创建 Notion 讲义页。
- `Codex Agent A/B/C`：当前真实可用流程，只保留自动填充考点、真题自动入库、生成教学页和一键执行 Codex A/B/C。
- `DeepSeek Agent A/B/C`：国产大模型改造入口；A 自动填充考点、B 真题自动入库、C 生成教学页已接入 DeepSeek API，并支持一键按 A → B → C 顺序串联执行。一键执行失败时停止后续步骤，已完成步骤保留各自日志、Notion 评论和数据库写入。
- `Codex Agent 显示控制`：老师端支持隐藏/显示 Codex Agent 卡片；显示状态下该卡片标题和一键按钮不出现 Codex 名称，只显示 `Agent A/B/C` 与 `一键执行 A/B/C`；隐藏状态下界面只显示一个 `显示` 按钮且不出现 Codex 名称。该开关只影响当前浏览器前端展示，不改变后端 Codex 能力。隐藏 Codex 后，DeepSeek Agent 自动成为第 2 步，后续流程编号顺延。
- `DeepSeek B 真题自动入库`：除 Notion 真题库候选外，也读取本地 SQLite 已沉淀题库作为跨章节候选，允许同一道真题按考点复用到多个章节；为保证 JSON 稳定性，DeepSeek B 只读取前 80 条精简候选，只返回最多 20 个候选题 `candidateId` 和摘要，不返回完整题干、选项、答案、解析，后端再按 ID 复制原题入库。DeepSeek B 采用 Notion AI 5 步选题法：锚定考纲关键词、完整阅读候选题库、排除相邻章节、判定边界题、形成课堂讲评题组；题型比例不固定，总数 20 和考点覆盖优先。DeepSeek B 作为参赛国产模型选题链路，选中的题目即使当前章节已有同题也继续插入，以保留本轮选题结果；如果 SQLite 唯一约束发现同章节同题同来源已存在，后端自动给 `source` 加 `（DeepSeek选题2）` 等后缀后再插入；若后续需要去重，可使用“清理当前章节重复题”。若 DeepSeek 偶发返回空内容或返回不足 20 题，后端启用候选排序兜底补齐，仍只从已有候选题中选择并写入 warning。
- `DeepSeek C 生成教学页`：复用 Codex C 的上下文、schema、Notion 写回和 SQLite 保存流程；默认使用 `DEEPSEEK_TEACHING_MODEL=deepseek-chat`，避免推理模型在长教学页任务中返回空 `content`；生成结果仍是待老师人工检查的草稿。DeepSeek C 生成的历年真题展示区必须按单选题、多选题、判断题、简答题、操作题的顺序排列；每个题型内部单独从 `1.` 开始编号，空题型不展示且不编造题目。
- `C 教学页真题导入边界`：Codex C 与 DeepSeek C 生成的“历年真题演练”区域必须包含纯文本独立行 `历年真题演练开始` 与 `历年真题演练结束`，用于老师端“导入当前章节习题”按区间解析历年真题；保存前会自动补齐缺失边界并记录 warning。
- `章节题库与教学页管理`：同步当前章节教学页、导入当前章节习题、显示/编辑章节习题、清理当前章节重复题。
- `章节题库分组显示`：题库按来源和题型两层展示。来源包括历年真题、模拟题、补充练习；每个来源内按单选题、多选题、判断题、简答题、操作题排序。数据库使用 `question_source_kind` 明确标记 `real_exam`、`mock_exam`、`manual`，避免依赖来源文案判断。
- `章节教学页预览`：老师端、学生端和公开试用页的 Markdown 预览支持 Mermaid 知识结构导图渲染；导图渲染失败时显示错误提示和原始 Mermaid 代码，方便老师检查语法。
- `Notion 自动化`：扫描 Notion 触发项。
- `导出`：导出演示 PPT、教学网页、章节题库和 Markdown。

### `/student`

学生学习首页。已授权学生登录成功后跳转到该路径。

### 工作台返回主页

老师端和学生端侧边栏都提供“返回公开主页”按钮。该操作只导航到 `/`，不退出登录。

## 文案边界

- 主页可使用“曾指导学生基于该作品桌面版参加计算机设计大赛，已获多省联赛一等奖，证书待下发”。
- 证书下发前，不写成已经拿到证书或已经完成证书交付。
- AI 相关内容必须强调教师人工审核后发布。

## 验收标准

- 未登录访问 `/` 能看到参赛主页和三个入口。
- 点击无需登录试用进入 `/trial`，不触发登录，并能看到 `第 1 章第 1 节-计算机概述` 的完整教学页。
- `/trial` 的练习题可在本地选择答案并查看解析，但不新增 `question_attempts` 记录。
- `/trial` 底部功能说明区显示 6 张图文卡片，桌面端 3 列、移动端单列展示，图片、标题、说明不重叠。
- 点击学生入口进入 `/login?role=student`。
- 点击老师入口进入 `/login?role=teacher`。
- 老师登录成功后进入 `/teacher`。
- 学生登录成功后进入 `/student`。
- 已登录用户访问 `/` 仍显示公开主页。
- 工作台点击“返回公开主页”后进入 `/`，且不退出登录。
- 移动端单列展示，按钮和指标不重叠。
- `npm run check` 和 `npm -w apps/web run build` 通过。
